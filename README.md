# Rewrite downloads

Installers for **Rewrite**, the reading and writing assistant from [rewrite4me.io](https://rewrite4me.io). Each release has:

- `Rewrite-<version>.dmg` – Mac (Intel and Apple Silicon, macOS 13+)
- `Rewrite-<version>.zip` – the same Mac app, used by the one-line Terminal installer on the website
- `Rewrite-Setup-<version>.exe` – Windows 10/11 installer (64-bit)

The source code is not in this repository; it only hosts release files.
